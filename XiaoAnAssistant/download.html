核心功能

登录功能 用户名+密码登录，任意输入即可进入

💬

📋 构建安装步骤

  1. 下载并安装 Android Studio
  2. 打开项目，等待 Gradle 同步完成
  3. 连接安卓平板（开启 USB 调试模式）
  4. 点击 Run 按钮或执行 ./gradlew assembleDebug
  5. APK 输出路径：app/build/outputs/apk/debug/
  6. 安装：adb install app-debug.apk

⚠️ 注意事项

• 语音识别功能需要联网（使用 Google 语音服务或国内语音输入法）
• 需要授予麦克风录音权限
• 建议在平板上安装 Google 语音搜索或讯飞语音输入法
• APK 文件需要自行构建生成
